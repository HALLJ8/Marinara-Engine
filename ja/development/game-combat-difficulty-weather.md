# 戦闘の難易度と天候

#6302のcombat directorに続く[#6305](https://github.com/Pasta-Devs/Marinara-Engine/issues/6305)の実装記録です。合意済み範囲と実装境界を記します。

## 設定と難易度

Battlefield Sizeを残し、Battlefield Seed入力/要約を削除します。新遭遇は内部ランダムシードを持ち、将来の開始では古いキャンペーンシード設定を無視します。受理済みシード、グリッド、再戦動作は保持します。Classicの説明を「Cinematic menu battles.」へ変更します。

旧設定の先頭大文字も含め、共通ヘルパーで難易度を正規化します。敵ダメージ倍率はCasual 0.6、Normal 1、Hard 1.3、Brutal 1.6です。ClassicもTactical同様、敵だけに適用します。遭遇/戦利品の大文字小文字も監査し、難易度は遭遇作成時に固定して戦闘中の設定変更に追従させません。

倍率はTraditional(現行の旧Engine機構)専用です。5e、V20、別ルールを実装する際は固有の難易度方針を検討し、Traditional倍率を既定で継承しません。AI判断調整とダメージ倍率は別です。

## 天候

既存キャンペーン天候と根拠ある遭遇の屋外/遮蔽状態を使います。受理天候を遭遇に保存し、旧保存の欠損は中立とします。不明は中立、閉鎖環境は遮蔽扱いです。別名を既存天候型へ正規化し、型設定時には対応する風/視界を生成します。

初期規則は両陣営へ等しく適用します。雨は火を少し弱め雷を強め、強風は明示投射攻撃、低視界は明示視認依存攻撃を弱めます。雪はTactical歩行費用を増やし、飛行/瞬間移動の意味は維持します。技名から投射/視認特性を推測せず、晴れ/曇りは通常中立です。共通ヘルパーで予測、解決、AI評価を一致させ、未来の戦闘乱数は消費しません。

両戦闘UIで受理条件/効果を示します。装飾天候設定で機構を無効にできません。遭遇中は固定し、天候変更能力、周期変化、ランダム落雷、暑さ消耗は延期します。Summoning/将来ルールは未完成モードUIを追加せず共通契約を再利用できます。

## 敵の判断

役割、性格、熟練度、合法性、資源会計を保ちます。難易度は有界なシード付き判断変動を変えます。Casualは妥当な間違いを増やし、Normalは現状近辺、Hardは一貫性を上げ、Brutalは熟練差を残して間違いを最小化します。仲間は常にNormal基準ですが、実天候/危険には反応します。Mindless制約は維持します。

攻撃、支援、位置、反応を天候込みで評価します。Counterspell/Guardは脅威、費用、性格に従いパスと競います。難易度で私的命令、未来の出目、無料資源、追加行動を与えません。GMには受理難易度/天候と圧力/機会選択の指針を渡し、Engineが合法候補/予算を強制します。失敗時はローカル代替を保ちます。

## 検証と提供

設定/正確性、天候、AI統合の順に実装します。大小文字、敵だけの倍率、曝露/別名/予測/移動、保存復元、決定的敵選択/仲間基準、反応費用/ボス文脈の回帰を残します。古いシード設定に合わせ既存設定/地形fixtureを更新し、両テーマ/デスクトップ/モバイルと天候アニメーション無効を試します。基準検証、関連プロンプト/ブラウザ回帰、ローカルCodeRabbitを経てdraftをreadyにします。

調整値は初期設計で、バランス実証ではありません。自動fixtureは機構/不変条件を示します。実GM品質/長期キャンペーンのバランスには試遊が必要です。延期issueは作業開始まで未割当とします。

## 実装詳細

共通条件は`packages/shared/src/features/combat-conditions.ts`です。設定輸入/作成、遭遇、戦利品、Classic/Tacticalで難易度を正規化します。敵判断変動はCasual/Normal/Hard/Brutalで2.5 / 1 / 0.4 / 0.15倍、保存熟練/性格は維持します。Classicは解決と同じ対抗d20命中確率、Tacticalは共通攻撃予測を使います。Tacticalの追跡は通常のプロファイルでは地形と天候の移動コストで経路を評価します。Mindlessは合法な経路を空間的な歩数の少なさで選びます。どちらも実際の移動時には地形と天候のコストを支払います。反応は脅威期待値/希少性を使い、同じ敵専用変動を適用します。

屋外の雨/大雨/嵐では火0.85倍、雷1.15倍です。明示投射は強風で命中10点、暴風で15点低下します。明示視認依存は視界低下で5点、悪視界で15点低下し、合計上限25点です。Classicは命中五点ごとに対抗ロール一点の修正へ変換し、条件表示で示します。Tacticalの屋外雪/吹雪は入るマスごとに歩行一点追加し、飛行/瞬間移動には影響しません。属性ダメージアイテムにも雨倍率を適用し、回復/状態時間は変えません。

生成器は基本攻撃/技の`projectile`/`requiresSight`真偽値と`battlefield.terrainBrief.exposure`を設定します。特性欠損は中立、明示曝露が優先です。認識できる閉鎖環境は遮蔽、屋外は曝露、曖昧なら不明です。永続天候を使い、欠損時は確定済みシーン値へ戻します。戦闘開始メッセージタグで、表示モードが追いつく前の背景天候進行を止めます。受理条件はdirector/Tactical状態に保存し、矛盾/不正輸入を拒否します。天候なし旧保存は中立、旧Tactical再戦も変更後天候を再取得せず受理条件(中立欠損を含む)を渡します。

旧設定フィールドは互換/安全のため輸入時検証しますが、正規化エクスポートから除きます。遭遇シードは復元/再戦/回帰再現用に保ちます。別用途のExperience世界シードは削除しません。

## 検証記録

ローカライズ、型、lint、本番ビルドを含む`pnpm check`と`pnpm version:check`がローカル成功しました。Nodeスイートは295回帰ファイルを扱い、同時ビルドで生成物が一時消えた五件も再実行成功しました。レビュー後は戦闘開始タグ、通常天候進行、重み追跡、難易度一貫性、反応資源、ボス文脈を再検証しました。

明色デスクトップ/暗色モバイルChromiumで設定/輸入、両戦闘、アニメーションなし天候、反応、再読込、地形代替、復元マップ隔離を検証しました。ローカルWebKitはlibicu74、libjpeg-turbo8、libmanette-0.2-0、gstreamer1.0-libav不足で起動できず、CI/手動確認項目です。最終レビューとランダムマップ反復結果はPRに記録します。
