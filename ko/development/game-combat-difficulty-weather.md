# 전투 난이도와 날씨

#6302의 전투 디렉터에 이어 진행한 [#6305](https://github.com/Pasta-Devs/Marinara-Engine/issues/6305)의 구현 기록입니다. 합의한 범위와 구현 경계를 정리합니다.

## 설정과 난이도

Battlefield Seed 필드와 요약을 없애고 Battlefield Size는 유지합니다. 새 조우에는 내부 무작위 시드를 부여합니다. 앞으로 전투를 시작할 때 폐기된 캠페인 시드 설정은 무시하되, 이미 확정한 전투 시드, 격자와 재시작 동작은 유지합니다. Classic의 설명은 "Cinematic menu battles."로 바꿉니다.

대문자로 시작하는 옛 설정까지 하나의 공유 헬퍼로 난이도를 정규화합니다. 적 피해 배율은 Casual 0.6, Normal 1, Hard 1.3, Brutal 1.6을 유지합니다. Classic도 Tactical처럼 적의 피해만 조정해야 합니다. 조우와 전리품에도 같은 대소문자 문제가 있는지 확인합니다. 난이도는 조우 생성 시 고정하며, 전투 중 설정을 바꿔도 변경하지 않습니다.

이 피해 배율은 Traditional(현재 Engine의 레거시 메커니즘)에만 속합니다. 5e, V20 또는 다른 규칙 집합을 구현할 때는 각 규칙 집합의 자체 정책으로 난이도를 다시 검토해야 합니다. Traditional 배율을 기본으로 상속하지 마세요. AI 의사결정 조정과 피해 배율 조정은 별개입니다.

## 날씨

기존 캠페인 날씨와 조우의 실제 노출 상태를 사용합니다. 확정한 날씨를 조우에 저장하며, 옛 전투 저장 데이터에 필드가 없으면 중립 효과로 처리합니다. 노출 여부가 불명확하면 중립입니다. 밀폐된 환경은 차폐 상태입니다. 현재 날씨 별칭을 기존 날씨 유형으로 정규화하고, 유형을 설정할 때 그에 맞는 바람과 가시성을 생성해야 합니다.

초기 규칙은 양측에 똑같이 적용합니다. 비는 화염 피해를 조금 줄이고 번개 피해를 늘립니다. 강풍은 투사체로 명시된 공격에 불이익을 주며, 나쁜 가시성은 시야가 필요하다고 명시된 공격에 불이익을 줍니다. 눈은 Tactical의 보행 비용을 늘립니다. 비행과 순간이동의 이동 의미는 유지합니다. 태그 없는 능력의 이름만 보고 투사체나 시야 특성을 추론하지 않습니다. 맑음과 흐림은 보통 중립입니다. 예측, 판정과 AI 추정은 공유 헬퍼를 사용하고 미래 전투 굴림을 소비하지 않아야 합니다.

두 전투 인터페이스에 확정한 조건과 효과를 표시합니다. 시각적 날씨 설정으로 메커니즘을 끌 수는 없습니다. 조우 중 날씨는 고정합니다. 날씨 변경 능력, 주기적 날씨 전환, 무작위 낙뢰와 더위에 따른 소모는 나중으로 미룹니다. Summoning과 향후 규칙 집합은 미완성 UI 모드를 추가하지 않고 공유 날씨 계약을 재사용할 수 있습니다.

## 적의 의사결정

역할, 성향 형용사, 숙련도, 행동 적법성과 자원 계산을 유지합니다. 난이도는 범위가 제한된 시드 기반 의사결정 변동을 바꿉니다. Casual에서는 그럴듯한 실수가 더 많고, Normal은 현재 기준에 가깝고, Hard는 더 일관적이며, Brutal은 숙련도 차이를 유지하면서 실수를 최소화합니다. 동료 의사결정 조정은 모든 난이도에서 고정된 Normal 기준을 씁니다. 동료는 여전히 실제 날씨와 위험에 반응합니다. Mindless 제한은 유지합니다.

공격, 지원, 위치 선정과 반응에 날씨를 반영한 점수를 사용합니다. Counterspell과 방어는 위협, 비용과 성격에 따라 넘기기와 경쟁합니다. 어떤 난이도에서도 숨겨진 명령, 미래 굴림, 무료 자원이나 추가 행동을 제공하지 않습니다. GM 보스 프롬프트에는 확정한 난이도와 날씨, 압박과 기회 선택 지침을 제공합니다. Engine은 여전히 제시된 적법한 선택과 예산을 강제합니다. 제공자 실패 시 로컬 대체 동작을 유지합니다.

## 검증과 전달

설정과 정확성, 날씨, AI 통합 순서로 구현합니다. 난이도 대소문자, 적에게만 적용되는 피해, 날씨 노출과 별칭 및 예측과 이동, 저장과 복원, 결정적인 적 선택과 동료 조정, 반응 비용과 보스 프롬프트 경계에 실행 가능한 회귀 검증을 추가합니다. 폐기된 시드 설정에 맞춰 기존 설정과 지형 픽스처를 갱신합니다. 날씨 애니메이션을 끈 경우까지 데스크톱, 모바일, 양쪽 테마를 확인합니다. 초안을 검토 준비 상태로 바꾸기 전에 기본 검사, 관련 프롬프트 및 브라우저 회귀 검사와 로컬 CodeRabbit을 실행합니다.

조정 수치는 초기 게임 설계값이며 균형이 입증된 값이 아닙니다. 자동 픽스처는 메커니즘과 불변 조건을 검증합니다. 실제 제공자의 보스 품질과 장기 캠페인 균형에는 플레이 테스트가 필요합니다. 나중으로 미룬 이슈는 실제로 작업을 시작할 때까지 담당자를 지정하지 않습니다.

## 구현 세부 사항

공유 조건은 `packages/shared/src/features/combat-conditions.ts`에 있습니다. 설정 가져오기와 생성, 조우, 전리품, Classic 및 Tactical 소비 지점에서 난이도를 정규화합니다. 적 의사결정 변동에는 Casual / Normal / Hard / Brutal 순서로 2.5 / 1 / 0.4 / 0.15를 곱하며, 저장된 숙련도와 성격은 유지합니다. Classic 추정에는 판정과 같은 대항 d20 명중 확률을 사용하고, Tactical 추정에는 공유 공격 예측을 사용합니다. Tactical 추적은 일반 프로필에서 지형과 날씨 비용으로 경로를 평가합니다. Mindless 유닛은 대신 적법한 경로 중 공간 이동 단계가 가장 적은 경로를 선택합니다. 두 정책 모두 실제 이동에는 지형과 날씨 비용을 지불합니다. 반응은 예상 위협과 자원 부족을 고려하며, 적에게만 같은 변동 정책을 적용합니다.

노출된 비, 폭우와 폭풍은 화염 피해에 0.85, 번개 피해에 1.15를 곱합니다. 명시적 투사체는 강풍에서 명중률 10점, 매우 강한 바람에서 15점을 잃습니다. 시야가 필요하다고 명시된 공격은 가시성 저하에서 5점, 나쁜 가시성에서 15점을 잃습니다. 합산 불이익은 최대 25점입니다. Classic은 이를 대항 공격 굴림 수정치로 바꾸며(명중률 5점당 1점), 조건 표시에서 해당 굴림 불이익을 명시합니다. Tactical에서 노출된 눈과 눈보라는 진입하는 칸마다 보행 비용을 1점 추가합니다. 비행과 순간이동에는 영향이 없습니다. 원소 피해 아이템에도 비 수정치를 적용하며, 치유와 상태 지속 시간에는 적용하지 않습니다.

조우 생성은 기본 공격과 스킬의 `projectile` / `requiresSight` 불리언 및 `battlefield.terrainBrief.exposure`를 작성합니다. 공격 특성이 없으면 중립입니다. 명시적 노출 설정을 우선하며, 인식 가능한 밀폐 환경은 차폐, 실외 환경은 노출, 모호한 환경은 불명으로 처리합니다. 캠페인 날씨는 저장된 날씨 시스템에서 가져오고, 없으면 확정된 장면 날씨 값으로 대체합니다. 전투 시작 메시지 태그는 렌더링된 모드가 바뀌기 전에 백그라운드 날씨 진행을 막습니다. 확정한 조건은 디렉터와 Tactical 상태에 저장하며, 모순되거나 잘못된 가져오기는 거부합니다. 날씨 없는 기존 저장 데이터는 중립으로 유지합니다. 레거시 Tactical 재시작은 변경된 캠페인 날씨를 다시 뽑지 않고, 중립인 부재 상태까지 포함한 확정 조건을 전달합니다.

설정 가져오기에서는 호환성과 안전을 위해 폐기된 필드도 계속 검증하지만, 정규화된 설정 내보내기에서는 제거합니다. Engine은 복원, 재시작과 회귀 재현을 위해 명시적 조우 시드를 유지합니다. 다른 용도로 쓰이는 Experience 월드 시드를 없애는 변경은 아닙니다.

## 검증 기록

로컬에서 기본 `pnpm check`(현지화, 타입, 린트, 프로덕션 빌드 포함)와 `pnpm version:check`를 통과했습니다. Node 모음은 회귀 파일 295개를 다뤘습니다. 동시 빌드로 생성 파일이 잠시 사라진 뒤 5개를 다시 실행해 통과했습니다. 검토 수정 뒤 들어오는 전투 태그, 비전투 날씨 진행, 가중 추적, 난이도 일관성, 반응 자원과 보스 맥락을 포함한 전투 회귀 검사를 다시 실행했습니다.

밝은 테마의 데스크톱 Chromium과 어두운 테마의 모바일 Chromium에서 설정과 가져오기, 두 전투 모드, 애니메이션을 끈 날씨, 반응, 새로고침, 지형 대체 동작과 복원한 지도 격리를 확인했습니다. 호스트에 libicu74, libjpeg-turbo8, libmanette-0.2-0, gstreamer1.0-libav가 없어 로컬 모바일 WebKit은 실행할 수 없었습니다. 해당 브라우저는 CI 및 수동 검증 항목으로 남습니다. PR에 최종 검토 결과와 무작위 지도 픽스처 반복 검사 결과를 기록했습니다.
